# Free asset research (Phase 3–5 input)

Gathered 2026-11-22. "Verified" = license read on the source page. Freesound entries were found via the CC0 filter — open each page to confirm before shipping.

## Picks
- **Character:** Quaternius Universal Base Characters (CC0, ~13k tris, rigged) + Universal Animation Library (CC0, GLB; idle/jog/sprint, 120+ clips — check for a jump/throw clip, else a custom shot pose). Fallback: Kenney Animated Characters / Mini Characters (CC0, lighter).
  - https://quaternius.com/packs/universalbasecharacters.html
  - https://quaternius.com/packs/universalanimationlibrary.html
- **Hoop + ball:** Poly Pizza "Basket ball and hoop" by Armory_3D (CC0, verified) — https://poly.pizza/m/i3LLacyQP4
- **Everything else** (court, bleachers, scoreboard, bench, trophies, locker props): build from R3F primitives — no CC0 3D sports pack exists. Generic furniture: Quaternius Furniture Low Poly (CC0, unverified) — https://opengameart.org/content/furniture-low-poly
- **Avoid:** Mixamo (not CC0; redistribution restricted), anything depicting real teams/leagues/logos.
